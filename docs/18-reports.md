# Reports

This page will describe the reports exposed through Modulus and how their
results should be interpreted. It will connect the stored activity and
membership data to the views available in an installation.

:::note[Documentation in Progress]
Documentation is actively being worked on. The report inventory and examples
are still being reviewed against the refactored core and host packages.
:::

## Planned Coverage

The reference will identify each report, its audience and required permissions,
its source data, time-window and aggregation rules, and any limitations. Worked
examples will use synthetic data and explain what each result measures.
