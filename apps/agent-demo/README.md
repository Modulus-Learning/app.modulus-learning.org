# Modulus Agent Demos

Example activity pages instrumented with `@modulus-learning/agent`, in React (`react/`) and plain HTML and JavaScript (`vanilla/`).

This is part of the [Modulus](https://modulus-learning.org/) source repository
and is not published to npm. Modulus connects a learning management system
(LMS) to open learning activities through LTI 1.3.

## Documentation

Documentation is being actively worked on following the package refactor.

- [Modulus website](https://modulus-learning.org/): the official documentation.
- [Source repository](https://github.com/Modulus-Learning/app.modulus-learning.org):
  the source code, issue tracker, and the guides under `docs/`.
