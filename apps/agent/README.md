# @modulus-learning/agent

The Modulus browser agent: a library that instruments activity pages so they can authenticate learners and report progress to a Modulus installation.

`@modulus-learning/agent` is part of [Modulus](https://modulus-learning.org/), which connects a
learning management system (LMS) to open learning activities through LTI 1.3.
The published `@modulus-learning/*` packages release together at the same
version.

```sh
npm install @modulus-learning/agent
```
