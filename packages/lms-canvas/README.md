# @modulus-learning/lms-canvas

The Canvas LMS adapter for Modulus, `canvasAdapter()`: roles, term fields, deep-link variables, registration defaults, and the Assignment and Grade Services (AGS) client.

`@modulus-learning/lms-canvas` is part of [Modulus](https://modulus-learning.org/), which connects a
learning management system (LMS) to open learning activities through LTI 1.3.
The published `@modulus-learning/*` packages release together at the same
version.

```sh
npm install @modulus-learning/lms-canvas
```
