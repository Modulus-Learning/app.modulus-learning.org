# @modulus-learning/lti

Shared LTI 1.3 vocabulary for Modulus (claims, messages, access tokens, and score results) and the `LmsAdapter` contract that LMS adapters implement.

`@modulus-learning/lti` is part of [Modulus](https://modulus-learning.org/), which connects a
learning management system (LMS) to open learning activities through LTI 1.3.
The published `@modulus-learning/*` packages release together at the same
version.

```sh
npm install @modulus-learning/lti
```
