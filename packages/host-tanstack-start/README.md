# @modulus-learning/host-tanstack-start

The TanStack Start host for Modulus: route factories, gated server functions, server-entry and router helpers, the admin and learner UI, a Vite preset, and styles.

`@modulus-learning/host-tanstack-start` is part of [Modulus](https://modulus-learning.org/), which connects a
learning management system (LMS) to open learning activities through LTI 1.3.
The published `@modulus-learning/*` packages release together at the same
version.

```sh
npm install @modulus-learning/host-tanstack-start
```
